# ✂️ Rock Paper Scissors Game

A simple, interactive, and responsive **Rock Paper Scissors (Gunting Batu Kertas)** web game built using **Vanilla HTML, CSS, and JavaScript**. This project focuses on fundamental **DOM Manipulation** and basic game logic implementation without relying on external libraries or frameworks.

---

## 🚀 Live Demo

👉 [Lihat Live Demo](https://hary300.github.io/Odin-Project-03-Rock-Paper-Scissor/)

---

## ✨ Features

- 🎮 **Player vs Computer Mode**: Play directly against a computer with random choices.
- ⚡ **Real-Time DOM Manipulation**: Dynamic update of choices, scores, and match results without reloading the page.
- 📱 **Responsive UI**: Fully accessible on desktop, tablet, and mobile browsers.

---

## 🛠️ Tech Stack & Concepts

- **HTML5**: Semantic layout and structure for game elements.
- **CSS3**: Styling, Flexbox/Grid alignment, hover effects, and button transitions.
- **JavaScript (ES6+)**:
  - **DOM Selection**: `document.querySelector()`, `document.querySelectorAll()`
  - **Event Handling**: `addEventListener()` for user click actions
  - **DOM Manipulation**: Updating `textContent`, and toggling dynamic CSS classes.
  - **Control Flow & Math**: `Math.random()` for AI decision-making and standard conditional logic (`if/else`).
